# Labb_2_21-09-25, Nikki Norberg
## Introduktion
Ett program där du gissar vad datorn tänker på för nummer.
Det finns tre svårighetsgrader och även ett alternativ för att skapa din egen svårighetsgrad. 

## Krav
- .NET 8.0 SDK
- Visual Studio 2022 eller senare (valfritt)

## Köra programmet
1. Klona repot: `git clone <repo-url>`
2. Gå in i mappen: `cd Labb_2_21-09-25`
3. Kör: `dotnet run`
